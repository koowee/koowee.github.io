Tämä sivu koskee lukemaasi verkkosivustoa. Jokaisella sovelluksella on oma tietosuojaselosteensa, johon on linkki sovelluksen sivulla.

## Ei evästeitä, ei analytiikkaa

Sivusto ei käytä evästeitä, analytiikkaa, seurantaa eikä ulkopuolisia skriptejä tai fontteja. Se ei pyydä eikä tallenna sinusta mitään tietoja.

## Ylläpito

Sivusto on staattinen, ja sitä ylläpitää GitHub Pages. Kuten mikä tahansa verkkopalvelin, GitHub voi kirjata teknisiä tietoja, kuten IP-osoitteesi, palvelun turvallisuuden vuoksi. Tätä koskee [GitHubin tietosuojaseloste](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement), eikä meillä ole pääsyä näihin tietoihin.
